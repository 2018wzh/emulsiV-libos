# Historical material

`preview1-tools/` preserves the former tool implementations as text.
These files describe version 0.1.0-preview.1. They are not executable project tools.
Their old paths, versions, dependencies, and release behavior are not current instructions.
The active implementation is the Rust workspace member in `xtask/`.

The Cargo library package and firmware ZIP exclude this directory.
Git history also preserves the original paths and content.

中文：此目录仅保存旧工具的历史文本，不属于当前构建或发布流程。
请使用 `cargo xtask help` 查看有效命令。
